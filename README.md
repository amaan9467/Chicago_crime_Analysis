🚨 Chicago Crime Analysis Dashboard (2014–2016) — Power BI Project

Transforming raw crime data into powerful, interactive insights using **Power BI** to support strategic decision-making and policy planning. This dashboard uncovers year-wise crime patterns, arrest trends, and high-risk zones across Chicago.

### 🔥 **Dashboard Highlights**

- ✅ **Year-wise Crime Mapping (2014–2016)** for trend visualization  
- ✅ **Arrest Trends** by crime type to explore enforcement outcomes  
- ✅ **District-wise Crime Breakdown** for geographic insights  
- ✅ **Top Crime Locations & Prevalent Crime Types** to identify hotspots and risk zones
